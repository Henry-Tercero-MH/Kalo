# Decisiones y pendientes

Decisiones que el prompt no definía: se eligió la opción más simple que no impide crecer.

## Decisiones técnicas

| #     | Decisión                                                                                                                                                                                                                                                                | Motivo                                                                                                                                                                                                   |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-001 | El monorepo vive en la raíz del repositorio `Kalo` (no en una subcarpeta `kalo-campo/`).                                                                                                                                                                                | El repositorio ya es exclusivo del proyecto; evita un nivel de carpetas.                                                                                                                                 |
| D-002 | pnpm con `node-linker=hoisted`.                                                                                                                                                                                                                                         | Metro/React Native y los módulos nativos de Expo resuelven dependencias de forma más predecible con dependencias elevadas. React se fija en la misma versión (19.2.3) en móvil y web para no duplicarlo. |
| D-003 | `@kalo/shared` y `@kalo/ui-tokens` se publican como TypeScript fuente.                                                                                                                                                                                                  | Metro, Next (`transpilePackages`) y `tsx` lo consumen directo; la API lo incluye en su bundle con `tsup`. Sin pasos de compilación intermedios.                                                          |
| D-004 | **Registro de tablas único** en `@kalo/shared` del que se generan el esquema de WatermelonDB y los Zod de validación; el esquema Drizzle se escribe a mano y una prueba verifica que coincidan.                                                                         | Una sola definición para celular y servidor sin perder índices, FK y columnas PostGIS en el servidor.                                                                                                    |
| D-005 | Modelos de WatermelonDB **generados** (sin decoradores); se accede a la fila tipada (`modelo.fila`) y se escribe con un repositorio (`crear`, `actualizar`, `borrarLogico`).                                                                                            | Agregar una tabla no exige escribir un modelo; tipos derivados del registro.                                                                                                                             |
| D-006 | Fechas de sincronización en milisegundos (`bigint`) en PostgreSQL.                                                                                                                                                                                                      | Es el formato de WatermelonDB; evita conversiones y errores de zona horaria en el protocolo. Fechas de negocio (`fecha`) como `date`.                                                                    |
| D-007 | **Cifrado de la base local: pendiente de endurecer.** WatermelonDB 0.28 no trae SQLCipher; hoy la protección es el cifrado de archivos de Android (FBE), los secretos en Keystore (`expo-secure-store`), el bloqueo por intentos de PIN y el borrado remoto.            | Integrar SQLCipher exige un parche nativo del adaptador SQLite de WatermelonDB (o cambiar de adaptador). Queda como siguiente paso documentado; el respaldo exportado sí va cifrado (AES-256-GCM).       |
| D-008 | PIN offline con PBKDF2-SHA256 (4.000 iteraciones) y sal por usuario; en el servidor, bcrypt.                                                                                                                                                                            | Un PIN de 4 dígitos no se protege solo con un hash; el hash evita guardarlo en claro y la seguridad real depende de D-007, el bloqueo y el borrado remoto.                                               |
| D-009 | La sincronización usa una **sesión de dispositivo** (refresh de 180 días) y verifica permisos del `created_by` de cada registro.                                                                                                                                        | Los usuarios inician sesión sin señal (sin token) y varios comparten un celular.                                                                                                                         |
| D-010 | Conflictos: la versión base de cada registro (`server_updated_at` local) se conserva en el `conflictResolver` y la app hace un segundo ciclo tras un push con escrituras.                                                                                               | Con el protocolo estándar, el celular que descarga primero el cambio ajeno «gana» aunque su edición sea más vieja y el servidor nunca ve el conflicto.                                                   |
| D-011 | «Más reciente campo por campo» usa el `updated_at` del registro como reloj de cada campo modificado.                                                                                                                                                                    | WatermelonDB no guarda hora por columna; agregarla duplicaría columnas. Los conflictos críticos los revisa el supervisor.                                                                                |
| D-012 | Bloqueo `pg_advisory_xact_lock` por finca (exclusivo en push y escrituras del panel, compartido en pull).                                                                                                                                                               | Garantiza que ningún cambio confirmado tarde quede con un `server_updated_at` anterior al de un pull ya entregado.                                                                                       |
| D-013 | Registros de campo: el celular descarga solo los últimos 60 días (`sync_dias_historial`).                                                                                                                                                                               | Limita espacio y tiempo de la primera descarga. Catálogos sin límite.                                                                                                                                    |
| D-014 | Los puntos GPS descartados por la simplificación se eliminan del celular antes de enviarse.                                                                                                                                                                             | Son muestras crudas del sensor, nunca registros del servidor; los registros sí se borran solo de forma lógica.                                                                                           |
| D-015 | Cobertura: celdas en la zona UTM del lote (calculada desde su centroide) con `ST_SquareGrid`; cuenta como recorrida si hay un punto a ≤ `cobertura_radio_m` (10 m).                                                                                                     | Metros reales sin depender de una proyección fija; radio editable.                                                                                                                                       |
| D-016 | Pronóstico: cada cohorte (lote + semana de enfunde + color) se reparte entre 11, 12 y 13 semanas según `distribucion_cosecha` (uniforme por defecto, **pendiente**), descontando lo ya cosechado o perdido; recobro observado por lote (13 semanas) o el de referencia. | El prompt da el rango 11–13 pero no el reparto.                                                                                                                                                          |
| D-017 | La ecuación productiva usa por defecto el **factor promedio anual** del calendario (editable en pantalla); el pronóstico semanal usa el factor de cada semana.                                                                                                          | La ecuación es anual (cajas/ha/año).                                                                                                                                                                     |
| D-018 | Panel: sesión en cookies httpOnly + proxy `/api/v1/*` en Next.                                                                                                                                                                                                          | El navegador no maneja tokens; la API sigue siendo la misma para todos los clientes.                                                                                                                     |
| D-019 | Fuentes Archivo y Anton empaquetadas (`@fontsource`, `@expo-google-fonts`) en lugar de cargarlas desde Google en tiempo de ejecución.                                                                                                                                   | Mismas fuentes de Google Fonts, pero funcionan sin internet y en builds sin red.                                                                                                                         |
| D-020 | Mapa base: estilo OpenFreeMap configurable (`*_MAP_STYLE_URL`); el panel cambia a un estilo de respaldo sin mapa base si no hay internet.                                                                                                                               | Sin llave de API para el demo; los lotes y capas siempre se ven.                                                                                                                                         |
| D-021 | El worker de MapLibre GL se copia a `apps/web/public/maplibre/` al compilar.                                                                                                                                                                                            | Turbopack no empaqueta el worker de módulo de MapLibre 6.                                                                                                                                                |
| D-022 | Zona horaria de la API fijada a `America/Guatemala` (`ZONA_HORARIA`).                                                                                                                                                                                                   | Semanas, fechas y cobertura deben coincidir con el calendario de la finca aunque el servidor esté en UTC.                                                                                                |
| D-023 | Sesión del celular: caduca tras `sesion_inactividad_min` (30) y se bloquea 5 min tras `login_intentos_max` (5) PIN fallidos.                                                                                                                                            | El prompt pide sesión con caducidad sin fijar valores; ambos son parámetros.                                                                                                                             |
| D-024 | La app se ejecuta con **build de desarrollo** (no Expo Go).                                                                                                                                                                                                             | WatermelonDB (JSI) y MapLibre son módulos nativos que Expo Go no incluye.                                                                                                                                |
| D-025 | La API corre fuera de Docker en desarrollo (`pnpm dev`); en Compose está bajo el perfil `api`.                                                                                                                                                                          | `docker compose up` + `pnpm dev` no deben pelear por el puerto 4000.                                                                                                                                     |
| D-026 | El color `verde600` de la guía es `#8bbb31` (en una primera lectura se transcribió mal como `#8bb331`; corregido).                                                                                                                                                      | Valor tomado del documento del prompt (sección «Diseño con la guía de marca Kalo»).                                                                                                                      |
